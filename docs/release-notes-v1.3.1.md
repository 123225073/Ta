# Ta Windows v1.3.1

v1.3.1 新增正式白色主题“瓷白典藏”，并保留 v1.3.0 的“夜幕玻璃”。两套主题共享同一套产品结构与交互，用户可以在标题栏一键切换。

## 瓷白典藏

- 暖瓷白背景、墨色正文、朱砂红主操作与玉石绿成功状态，避免简单反色造成的刺眼和廉价感。
- 工作台、素材库、设置页、截图结果、AI/OCR 结果面板和标注编辑区全部适配。
- 截图结果与标注画布保留中性深浅对比，白色图片也能看清边界。
- 卡片、工具栏和输入框使用克制的描边、层级阴影与纸张质感，不使用大面积炫彩渐变。

## 快速切换与持久化

- 标题栏右侧、窗口按钮左边新增“瓷白 / 夜幕”切换按钮，所有主要页面均可直接使用。
- 点击后立即切换并写入本地设置，无需进入设置页再次保存。
- 下次启动继续使用上次选择；旧版本用户首次升级仍保持原有夜幕主题。
- 切换按钮提供明确的辅助技术标签、键盘焦点与非拖动点击区域。

## 验证

- 16 个测试文件、82 项单元与组件测试通过。
- 真实 Electron E2E 验证默认夜幕、切换瓷白、设置落盘和标题栏点击/拖动边界。
- 白色主题实际截图覆盖工作台、设置、素材库、结果与标注页。
- 完整安装和覆盖升级证据见 [Windows 验收报告](./windows-acceptance.md)。
