# 拓 Ta 1.13.0：一个 MP4，保留独立声音

- 录屏默认只保留一份 MP4。同时录制麦克风和电脑声音时，文件包含一份画面、一条默认混合音轨，以及两条独立压缩音轨。只有一个声源时复用同一条音轨，不额外复制。
- 设置增加“保留无损原始素材”，默认关闭，按录制开始时的设置决定该项目是否保留底稿。关闭时在成品时长、轨道、抽样解码和视频内容核验成功后，清理录制画面副本与 WAV；失败时保留底稿。
- 剪辑可以分别播放、静音和调节两种声音；SOP 和 CLI 截帧直接读取 MP4，不需要恢复整份视频底稿。预览所需的压缩音轨临时提取，关闭录屏工作窗口后清理。
- 普通“另存视频”提供一条混合音轨，便于播放器和 AI 处理；画面及混合声音直接复制封装，不重新编码。打开目录取出的内部原片保留全部独立音轨。
- 单声源录音只保留 MP3；双声源录音除 MP3 外保留一份小体积 M4A 独立音轨文件，以便后续分别取用声音，不保留大体积 WAV。
- 旧素材整理采用先生成多轨成品、核验、输出清理清单，再单独执行清理。清理限于该项目的 `screen.mp4`、WAV 与旧 `exports/source-时间戳/source.mp4`；名称、录制日期、编辑记录、SOP 和配图保留。

无损 WAV 与压缩独立音轨不同：后者保留分别编辑的能力，但不能恢复压缩前的音频质量。第三方剪辑、转码或平台处理后，额外音轨可能被丢弃，请保留软件中的原片作为后续编辑来源。

验证：162 项单元测试与类型检查通过；实际双声源录屏、MP3 录音、暂停/继续、重命名、设置持久化、原片另存及开发版/打包版预览通过。独立频率信号测试确认两条声音互不混入，删除底稿后仍可分别静音导出、SOP 截帧、CLI 截帧；保留底稿开关与保存失败保留原始素材通过。窗口录制异常、切换范围及声音连续性回归通过。
