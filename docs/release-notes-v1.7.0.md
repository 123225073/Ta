# 拓 Ta 1.7.0：大屏预览、飞书自动配置与多轨道剪辑

## SOP 来源视频

点击来源视频或「放大查看」，即可在大窗口中定位画面；「全屏 / 最大化」用于占满屏幕。放大窗口提供 150%、200%、300% 查看倍率，可滚动查看细节。播放位置保持不变，仍可逐帧定位、输入秒数和插入当前视频帧。Esc 可退出全屏或收起放大预览。

## 飞书一键配置

打开「设置 → 飞书云文档」或 SOP 顶部「飞书配置」，软件会自动寻找本机 CLI 并列出已有账号。

- 已安装：点击「一键配置」，复用检测到的账号并检查连接。需要切换时，从账号列表选择后保存。
- 未安装：点击「一键安装并配置」，下载官方 Windows 程序，验证 SHA-256 后安装到拓 Ta 自己的用户目录。
- 首次配置：扫码或打开飞书官方页面完成应用配置，再点击「登录 / 重新授权」完成云文档授权。授权链接与二维码同时显示。
- 已有账号登录失效：点击「登录 / 重新授权」，完成后点击「已完成授权」。

通常无需填写程序路径或配置名称；手工程序选择保留在「高级设置」。保存位置可粘贴文件夹或知识库链接，也可留空。授权与密钥仍由官方 CLI 管理。

## 教学视频时间线

视频、音频、标记和区域缩放有各自的轨道。可以增加轨道、选择片段、调整所在轨道、隐藏或静音整条轨道。补充视频默认作为画中画加入，可以在片段属性中调整位置和大小；后添加的画面显示在上层。

1. **分割与选中**：选择片段，将播放头移到分割位置，点击「当前帧分割」或按 Ctrl+B。分割后的片段可以独立选中。
2. **移动与删除**：拖动片段改变开始时间，也可输入「开始（秒）」；Delete 删除选中片段。至少保留一段视频。移动和删除不会自动吸合后续片段，留下的空白时间显示黑场。
3. **加速与减速**：拖动右边缘拉长或缩短片段，对应减速或加速；也可选择 0.25–4 倍速度或输入结束时间。左边缘用于裁切素材；素材入点、出点可以精确填写。
4. **声音同步**：原录制画面和麦克风、电脑声音关联，分割、移动、删除、变速一起生效；声音音量仍可单独调整。添加的其他素材独立编辑。
5. **局部放大**：将播放头放到开始处，点击「框选放大区域」，在预览中框选。自动生成约 3 秒的缩放片段，包含平滑放大、保持、恢复的关键帧。选中该片段可修改开始、结束时间，也可重新框选区域。
6. **关键帧**：选择视频或缩放片段，将播放头移到目标时刻，设置倍率、中心 X/Y，或点击「当前帧关键帧」。列表可直接修改关键帧时间、跳转和删除；关键帧间平滑变化。
7. **标记**：在预览中添加矩形、箭头、高亮、文字、遮挡，默认只出现 3 秒。选中标记片段调整起止时间；取消勾选后保留在项目中，预览和导出均隐藏。

Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做。一次拖动算一次编辑；导入素材、新增轨道、分割、移动、变速和关键帧均进入本地编辑历史。原始录像、原始声音与 SOP 的原视频时间引用保留，剪辑结果另存为 MP4。

## 范围与参考

本版实现教学录屏常用的多轨编辑和画面缩放关键帧，不包含剪映的完整特效、模板、转场、变速曲线、字幕动画或物体自动跟踪。

交互参考 [CapCut 时间线与片段操作](https://www.capcut.com/resource/how-to-use-capcut)及[关键帧说明](https://www.capcut.com/resource/how-to-add-keyframes-in-capcut)，没有复制其专有代码或素材。飞书自动检测流程参考本机 SAP 工作台的既有实现，安装程序来自 [larksuite/cli](https://github.com/larksuite/cli)。

飞书首次授权必须由用户在官方页面完成。连接检测与安装测试不等同于真实文档发布验收；本次未向用户云空间创建测试文档。
