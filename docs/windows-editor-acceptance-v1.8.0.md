# Windows 1.8.0 编辑交互验收

## 修复依据

- 正式入口的 `setPermissionRequestHandler` 原来拒绝所有权限请求，包含 HTML 全屏。独立测试没有安装同一策略，所以旧测试漏过此问题。现在仅允许本应用录屏编辑器进入全屏；测试使用同一判定函数，其他窗口和媒体权限仍被拒绝。
- 原时间线缩放下限固定为 5 像素/秒；现在按可用宽度计算完整适配，刻度间距动态调整，并避免末尾超出总时长的刻度制造额外横向滚动。
- 新建素材原来通过“选中片段”推断目标轨道，空轨道没有选择状态。现在轨道和片段分别选中，新增、导入和粘贴均使用对应目标轨道。
- 文字原来使用固定字号和侧栏输入。现在直接在画面编辑，新增字号字段兼容旧项目；SVG 预览与 MP4 导出共用换行和字号逻辑。
