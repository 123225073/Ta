# Ta Windows v1.1.1 对抗式审查

审查日期：2026-08-27。范围限定为 `windows/` 客户端，攻击面包括 Electron 窗口生命周期、IPC、图片与文本输入、协议与本地文件、外部链接、模型配置、云端上传、网络响应和安装升级。

## 已确认并修复

| 编号 | 问题 | 对抗方式 | 处置与证据 |
|---|---|---|---|
| TA-WIN-001 | 覆盖层销毁后，`closed` 回调读取已销毁的 `webContents.id`，导致主进程崩溃 | 单窗口、32 窗口、重复关闭、窗口自行关闭 | 创建时缓存 ID；会话表先清空再销毁；4 项生命周期回归测试通过 |
| TA-WIN-002 | 同一个 preload 暴露给主窗口、覆盖层和钉图，子窗口可尝试调用超出职责的 IPC | 从错误窗口伪造设置、历史、图片和导航请求 | 主进程按主窗口、覆盖层、钉图三种角色校验发送者；越权请求拒绝或忽略 |
| TA-WIN-003 | `NaN`、`Infinity`、负数和越界选区可能触发原生图片裁剪异常 | 伪造选区 IPC | 主进程验证有限数值、最小尺寸与显示器边界；恶意输入测试通过 |
| TA-WIN-004 | 超大或伪造 PNG、超长文字可能消耗大量内存 | 伪造 Base64、错误 PNG 签名、超限数据 | PNG 严格签名/Base64/80 MiB/1.2 亿像素限制，文字限制 2,000,000 字符 |
| TA-WIN-005 | 任意协议可传给 `shell.openExternal` | `file:`、自定义协议、含账号密码 URL | 仅允许不含凭据的 HTTP/HTTPS；所有窗口统一阻止新窗口 |
| TA-WIN-006 | 云端上传确认只在渲染层，遭到页面绕过后可直接调用模型 IPC | 直接调用 `ai:run` | 确认迁移到主进程原生对话框；渲染层无法绕过 |
| TA-WIN-007 | 被篡改的历史索引可把文件名指向历史目录外 | `../` 文件名、伪造历史 ID | ID 与 `${id}.png` 必须匹配，解析路径必须仍在历史目录 |
| TA-WIN-008 | 模型服务可无限等待或返回超大响应 | 慢服务、超大响应、跨站重定向 | 90 秒超时、2 MiB 响应上限、禁止重定向、设置入口限制 HTTP/HTTPS Base URL |
| TA-WIN-009 | 测试被已有单实例锁拦截时只会空等 | 先运行安装版再执行 E2E | E2E 侦测子进程提前退出并立即给出单实例提示 |

## 验证

- `npm test`：4 个文件、15 个测试通过。
- `npm run typecheck`：Electron 与 React TypeScript 均为 0 错误。
- `npm run smoke:e2e`：真实桌面 3073×1921、本地 OCR 95%、覆盖层 1/1、`safeStorage` 回环通过。
- 安装版 E2E：与源码版相同的桌面捕获、OCR、覆盖层和安全存储检查通过。
- `npm audit --omit=dev --registry=https://registry.npmjs.org`：0 个已知生产依赖漏洞。
- CPA 真实视觉回环：仅发送包含随机测试码的合成图片，`fengsha-cpa / gpt-5.5` 正确识别；没有上传用户桌面或业务截图。

## 剩余边界

- 安装包没有商业代码签名，Windows SmartScreen 信誉不属于本地代码审查可解决范围。
- 第三方模型服务会接收用户确认发送的截图，其日志、留存和账号权限由服务端策略决定。
- Codex Security 官方 Deep Scan 因当前任务没有受管理的文件系统权限配置而未启动；本文件是本地代码、恶意输入和真实运行审查，不能冒充该插件的扫描报告。
