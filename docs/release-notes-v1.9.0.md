# 拓 Ta Windows 1.9.0：标记交互修正与 AI 剪辑 CLI

## 标记操作

- 箭头严格使用鼠标按下位置作为起点、松开位置作为终点，支持水平、垂直及任意反向拖动；拖动时显示真正的箭头预览。
- 选中箭头后，分别拖动起点和终点调整方向与长度，中间手柄移动整体，上方手柄旋转。右侧可以精确填写起止坐标、角度和线宽。
- 文字改为单击画面立即创建标准输入框，不必框选范围。默认随内容展开，不再被窄框强制折行；旧文字也默认修正为此行为。主动换行仍保留，可取消“随文字展开”恢复固定宽度换行。
- 文字支持移动、等比缩放、旋转、字号、颜色和横排/竖排；Ctrl+Enter 完成编辑，Esc 取消本次输入。旋转手柄与快捷栏分开，避免被遮挡。
- 新建高亮使用聚光效果：框内保留原画面，周围变暗，可调整暗度。旧荧光笔标记保持原效果，可在右侧切换为“聚光：周围变暗”。
- 矩形、遮挡及聚光区域可以独立改变宽高，按 Shift 等比缩放。文字保持等比缩放，字号同步改变。
- 预览、CLI 与 MP4 共用标记绘制和几何逻辑；所有文档编辑仍可撤销，原视频保留。

交互参考 [Snagit 的箭头端点与选择手柄](https://assets.techsmith.com/Docs/pdf-snagit/Snagit-10-Help.pdf) 和 [CapCut 的画面/时间线文字选中方式](https://www.capcut.com/help/edit-the-text)，具体高亮语义按本次用户要求实现。

## AI 自动编辑

安装目录中的 `resources/cli/ta-video.cmd` 无需额外安装依赖或填写密钥。可将这个入口及同目录的 `AI-EDITING.md` 交给 Codex 等 AI。

提供项目查询、原片截帧、轨道与片段操作、文字/箭头/聚光/关键帧编辑、导入音视频、批量预演与应用、撤销/重做和 MP4 导出。自然语言理解由调用 CLI 的 AI 完成；本次没有新增应用内视频聊天模型，也不自动上传录像。

一次批量编辑作为一个撤销单元；版本校验防止覆盖用户刚做的修改。编辑器开着时先保存，再重新打开修改后的项目，界面 Ctrl+Z 也可撤销刚完成的 CLI 编辑。已有导出文件不会被覆盖。

详见 [AI 调用说明](../windows/resources/cli/AI-EDITING.md)。
