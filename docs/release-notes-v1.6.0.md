# 拓 Ta 1.6.0：视频定位、撤销与飞书发布

## 定位并插入视频帧

来源视频现在有独立进度条、播放/暂停、静音、逐帧按钮和秒数输入框。输入秒数后按 Enter 或点击其他位置确认。插入、替换配图时，会等待视频定位完成，使用播放器实际停留的时间截帧。

修正本地媒体接口的字节范围响应。原生录屏的分段 MP4 以前可能只被识别出开头几十秒，无法正确拖动；现在返回完整文件长度与 HTTP 206 分段内容，播放器可读取完整时长并跳转。原始录像不变。

## 撤销与重做

- SOP 顶部提供撤销、重做；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
- 覆盖标题、正文、生成要求、字幕、步骤添加/删除/排序、配图添加/替换/移除/加工、AI 生成与对话修改、历史版本恢复。
- 一次 AI 修改整体撤销；连续输入适当合并，自动保存不影响撤销。当前打开的 SOP 保留最近 100 次操作，重新打开后可使用历史版本恢复。
- 视频剪辑已有的撤销与重做也支持上述快捷键。
- 撤销作用于本地编辑。导出的文件和已发布飞书文档不会被 Ctrl+Z 删除。聊天输入草稿和时间输入框保留各自的文字撤销行为。

## 配置飞书 CLI

1. 打开「录屏与 SOP → 设置 → 飞书云文档」，或 SOP 顶部「飞书配置」。
2. 自动识别 npm 全局安装的 `lark-cli.exe`，也可手动选择。CLI 使用官方 `@larksuite/cli`；未安装时，界面提供安装及登录命令。
3. 配置名称留空使用 CLI 默认配置；需要指定账号时填写已有 profile 名称。软件复用 CLI 登录，不保存飞书密钥。
4. 可填写飞书文件夹、知识库链接或 token；留空使用默认位置。保存配置并测试连接。
5. 在 SOP 顶部点击「发布到飞书」。软件会以用户身份新建文档，按顺序上传步骤、配图、完成状态及提示，完成后可打开文档。

发布会发送当前 SOP 和所用配图，不上传整段原视频。每次点击发布都会创建新文档，不覆盖之前的版本。中途失败会保留已创建文档链接，不自动重试、不删除云端文档。发布记录保存在本机，重新打开 SOP 后仍可查看。

Word、PDF、HTML、Markdown 本地导出保持可用。

## 验证范围

自动测试覆盖媒体范围响应、编辑历史、飞书参数与图文顺序、部分失败处理。Electron 界面回归覆盖时间输入、进度条跳转、对应帧插入、Ctrl+Z/重做、AI 整体撤销、步骤与配图撤销、配置持久化及现有四种导出。

飞书 CLI 的现有登录通过实际只读连接验证。云文档创建和配图发布使用模拟 CLI 回归，未向用户空间创建测试文档；实际目标文件夹/知识库权限及云端图文效果尚未实测。
