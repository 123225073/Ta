# Ta Windows v1.1.10

发布日期：2026-08-28

## 本次修复

- 去除框选画面的模糊感：冻结预览不再把 3072px 桌面缩小到 896px 并使用双线性插值、JPEG 76 压缩后重新放大。
- Windows 原生截图辅助进程现在直接保存与物理屏幕同尺寸的无损 PNG；预览与最终裁图使用同一次桌面冻结中的原始像素。
- “复制图片”更名为“快速截图”：框选完成后自动复制到剪贴板、保存到最近拓片并关闭覆盖层，不打开图片编辑页。
- 工作台、设置、覆盖层提示、历史记录和系统托盘统一使用“快速截图”名称；原有 `Ctrl+Shift+3` 快捷键及用户自定义配置保持兼容。

## 回归保障

- 新增 `npm run test:preview-fidelity`，真实启动 Windows GDI 辅助进程，逐屏验证预览为全分辨率无损 PNG，并抽样比对预览像素与最终 BGRA 原图。
- 端到端测试新增快速截图断言：界面文案、自动复制、历史落盘以及不进入编辑页四项必须同时通过。
- 多显示器、DPI 映射、窗口智能框选、黑图防护、选区移动/缩放/双击、历史恢复、结果缓存和钉图功能继续纳入完整回归。

## 兼容说明

- 内部动作标识仍保留为 `copy`，避免破坏旧版快捷键设置和历史记录；仅对用户显示为“快速截图”。
- 原位升级不会清除截图历史、快捷键、窗口策略或已由 Windows `safeStorage` 加密的 CPA Key。
