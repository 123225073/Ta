# Ta Windows v1.3.0

v1.3.0 统一升级了拓的桌面视觉系统，并补齐编辑区键盘返回操作。现有素材结构保持兼容，仅为新外部截图增加可选来源软件字段。

## 交互改进

- 图片进入标注编辑区后，按 `Esc` 可立即退出，行为与“取消/返回”按钮一致。
- 编辑区取消按钮显示 `Esc` 提示，降低快捷操作的发现成本。
- 安装版 E2E 使用真实 Electron 键盘事件验证 `Esc → 返回结果页`，不是只测试辅助函数。

## 视觉升级

- 新设计方向为“夜幕玻璃 · 电光朱砂”：冷黑工作台、朱砂红品牌操作、薄荷绿捕获/可信状态。
- 首页、素材库、设置页、截图结果、AI/OCR 面板和标注工具栏统一为一套深色层级。
- 素材卡片改为数字底片台风格，强化缩略图、来源与选择状态。
- 新增统一聚焦环、状态发光、层级阴影、首次进入动效和减少动态效果适配。
- 正式客户端继续只使用 Windows 本地字体，离线启动不依赖字体 CDN。

## 设计资产

- 根目录新增 `DESIGN.md`，作为颜色、字体、间距、圆角、动效和风险取舍的统一基准。
- 新增 `docs/design-preview-v1.3.0.html`，可独立查看明暗模式、字体、色板以及工作台/素材库/设置示例。

## 对抗式审查修复

- 移除“收集该软件复制的所有图片”模式；飞书、微信和 QQ 只能走严格截图识别，旧设置中的该值会自动收紧为严格模式，不影响其他设置。
- 飞书默认截图快捷键除物理按键、可信进程、置顶窗口、PID/路径和剪贴板序列外，新增“无边框弹出层 + 覆盖大部分屏幕”的截图表面校验，排除普通会议浮窗与最大化聊天窗口。
- 外部截图现在持久化来源软件，素材卡可准确显示“飞书截图 / 微信截图 / QQ截图”。
- 修复第 51 张以后素材打开时丢失原动作和创建时间的问题。
- 页面切换会清除旧通知；补充通知朗读语义、工具选中语义、素材元信息对比度和减少动态效果适配。

完整安装和验证证据见 [Windows 验收报告](./windows-acceptance.md)。
