# Ta Windows v1.3.2

v1.3.2 修复浏览器长截图中固定工具栏随每一帧重复出现的问题，并让自动滚动、内容识别和拼接过程对用户清晰可见。

## 主要变化

- 长截图仍只读取用户确认的选中边框；拼接前会识别选区内不随页面滚动的顶部、底部固定区域。
- 固定浏览器栏、网页吸顶栏或底部悬浮栏从各帧滚动正文中分离，最终成品只保留一次。
- 新增长截图状态浮层，实时显示准备、已识别帧数、页面自动下滑、固定栏分析、拼接和完成状态。
- 状态浮层不获取焦点、不接收鼠标；每次读取屏幕像素前会临时隐藏，采集完成后恢复，因此不会进入长截图。
- 状态动效沿用“夜幕玻璃 · 电光朱砂”捕获状态色，并遵循系统的减少动态效果设置。

## 验证

- 增加含固定浏览器顶栏、滚动正文和固定底栏的精确回归图像：三帧拼接后，顶栏和底栏像素行数均严格等于单帧一次。
- 真实 Electron E2E 验证状态浮层显示 `FRAME 03 / 12` 和“页面正在自动下滑”，并验证采集前隐藏、采集后恢复。
- 保留既有截图、快速截图、OCR、AI、素材库、标注、`Esc` 返回、双主题、钉图、快捷键和安全存储验证。

## 已知边界

- 视频、持续动画、虚拟列表、滚动时大幅重排或覆盖选区大部分面积的动态悬浮层，仍可能降低相邻帧匹配质量。
- 安装包未做商业 Authenticode 代码签名，Windows SmartScreen 可能提示未知发布者。
