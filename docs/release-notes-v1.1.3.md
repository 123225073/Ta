# Ta Windows v1.1.3

发布日期：2026-08-27

## 性能优化

- 截图覆盖层在应用启动后预热，不再每次按快捷键时重新创建和加载页面。
- 在 Windows 10 2004 及更新系统上，受保护透明覆盖层先立即接管鼠标，桌面原始画面在后台冻结。
- 多显示器截图源改为一次获取，避免按显示器数量重复调用桌面捕获。
- 预览图按显示器逻辑分辨率生成高质量 JPEG；最终裁图仍使用主进程保存的全分辨率原图，不降低输出质量。
- 取消截图会让正在进行的旧捕获失效，避免旧结果污染下一次截图。

## 实测

- 优化前：1,388–1,426 ms 才能进入可框选状态。
- 优化后：多轮首次/第二次截图为 110–247 ms。
- 自动回归上限：300 ms。
