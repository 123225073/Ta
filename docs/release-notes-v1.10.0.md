# 拓 Ta 1.10.0：教程视频编辑操作优化

录屏和 SOP 工作流保持兼容，这次集中改善视频剪辑的常用操作。

1. 时间线默认适应整段视频。Ctrl / Shift + 单击多选，Ctrl+A 全选；选中片段可一起移动、复制、粘贴、分割或删除。原录制声音随视频同步，拖动一次对应一次撤销。
2. 默认拖动片段边缘裁剪内容，不改变速度。需要拉长或缩短播放时间时，将「边缘操作」切为「变速」，拖动右边缘；也可在属性中选择速度。
3. 吸附对齐播放头、其他片段边缘和关键帧。按住 Alt 可临时关闭吸附。删除并合拢会保护仍跨越选中时段的其他素材，避免误删教程内容。
4. 框选放大区域后，在「局部放大」填写开始、结束、倍率及进入和退出时长，点击应用。支持平滑、匀速和直接切换；高级关键帧仍可单独编辑。
5. 音频轨显示从实际素材生成的波形，帮助定位讲解和停顿。波形异步生成；失败时显示状态，不影响原音频。
6. 属性面板减少重复控件，轨道类型放入下拉选择；保留面板分隔条、轨道高度、时间线缩放、精确秒数定位和全屏预览。
7. CLI 新增批量移动、批量删除、裁剪和放大时段配置，与界面共用时间编辑规则。保留 dry-run、版本检查、整批撤销，详见 `windows/resources/cli/AI-EDITING.md`。

参考 OpenCut Classic 的时间线吸附、命令执行和动画组织方式，按 Ta 的本地项目及 FFmpeg 导出机制独立实现。没有嵌入 OpenCut 网站或替换为其尚在重写中的编辑器。参考来源见 [OpenCut 参考与取舍](opencut-integration.md)。

Ctrl+F1 调出主界面，Ctrl+F2 调出录屏界面；应用需保持后台运行。
