# 拓 Ta Windows 1.8.0

这次更新集中改善教程视频的剪辑操作。

- 修复正式软件中全屏请求被拦截的问题。全屏预览保留播放、逐帧、进度条和退出按钮，也可用 Esc 退出。
- 拖动预览与时间线之间的分隔条调整上下空间；拖动右侧分隔条调整属性面板宽度。轨道高度可以单独缩小。
- “适应全部”完整显示长视频；加减按钮、缩放滑杆和 Ctrl+滚轮可放大精修。缩放以播放头为参照，刻度随比例调整。
- 点击轨道名称或空白处即可选中轨道。新建轨道会自动选中并滚动显示，新增同类素材进入该轨道。不同类型的素材仍分轨管理。
- Ctrl+C / Ctrl+V 或“复制 / 粘贴”按钮，将选中片段复制到播放头位置及选中的同类轨道。原录制画面与关联声音一起复制，副本可独立编辑；支持撤销和重做。当前复制范围为本项目。
- 点击“文字”，在画面单击或拖出文本框即可输入。双击已有文字继续编辑，Ctrl+Enter 完成，Esc 取消本次文字修改。支持多行文字。
- 画面上的标记可拖动移动，通过右下角手柄缩放；文字同步改变字号。选中文字后的快捷栏可调字号和颜色，右侧也可精确设置。
- 文字初始字号适配录屏分辨率，预览与导出使用相同的字号和换行规则。拖长标记或缩放轨上的片段直接改变持续时间；音视频片段右边缘仍用于变速。

参考了 [CapCut 的画布与时间线选中方式](https://www.capcut.com/help/edit-the-text)、[复制文字片段的操作](https://www.capcut.com/help/batch-edit-text) 和 [剪辑工作流](https://www.capcut.com/resource/how-to-use-capcut)，沿用本项目的设计系统与现有渲染器。

原录屏、SOP、CPA 和飞书配置均沿用。视频编辑仍是非破坏性编辑，原视频文件保留。
