# Ta Windows v1.1.6

发布日期：2026-08-28

## 同一截图的工具结果缓存

- 本地取字、AI 识图和截图翻译各自保存独立结果；切换功能或关闭侧栏后再返回，直接恢复本次截图的结果，不重复识别、不重复上传。
- 工具栏用绿色状态点表示该功能已有结果，侧栏明确显示“已保留在本次截图”。
- 每个结果提供“重新识别”按钮；只有用户主动点击才重新执行并覆盖该功能的旧结果。
- 缓存只属于当前截图；打开新截图，或通过标注、美化生成新图片时自动清空，避免把旧图结果误用到新图。
- 快速切换或重新识别时使用请求代次隔离，过期响应不会覆盖最新结果。
- 取消云端上传不再显示 Electron IPC 技术错误，改为“未发送截图。需要时可点击重新识别”。

## 首次截图延迟稳定性

- Windows 捕获辅助进程在后台启动时预分配各显示器的全分辨率 GDI 位图，不再等用户第一次点击时分配大块内存。
- 每次截图完成后立即把复用位图清黑；减少后续分配抖动，同时不让辅助进程继续保留桌面像素。
- 显示器数量、分辨率或位置改变时自动重建位图，避免复用过期屏幕尺寸。
- 复用覆盖窗口先等待渲染层确认已清除旧截图，再进入可见捕获态，消除偶发把上一轮暗色遮罩截进新图的竞态。
- 黑图检测触发后，先隐藏覆盖层并用已预热的 GDI 重新捕获；仍不合格才使用 Electron/DXGI 兜底，避免 DXGI 暂时不可用时产出黑图。

## 验收

- 状态机单元测试覆盖结果保留、显式重跑、取消提示和过期响应，共 3 项。
- 真实结果页 E2E 依次点击 AI 识图、翻译、返回 AI 识图：识图/翻译调用次数保持 1/1；点击重新识别后识图才增加为 2。
- 原有截图、黑图防护、双显示器、选区、历史恢复、钉图和 Electron 回退链路继续回归。
- 双显示器辅助进程基准中，后续冻结预览由约 156–160 ms 降至约 99–109 ms。真实应用分别约束输入接管、首次冻结与连续冻结：硬上限为 180/550/350 ms，避免把“鼠标已可操作”和“双屏预览全部完成”混成一个指标。
