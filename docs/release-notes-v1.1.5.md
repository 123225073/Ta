# Ta Windows v1.1.5

发布日期：2026-08-28

## 修复

- 修复 Windows 10 上偶发整屏变黑、最终截图也为纯黑的问题。根因是受保护的全屏 Electron 覆盖层在部分 DWM/显卡驱动组合上没有被稳定排除，而是被捕获为黑色窗口。
- Windows 10 改用随应用预热的隐藏 GDI 捕获；支持多显示器先统一冻结全部桌面像素，画面冻结后再显示框选界面。
- 原生捕获改为两阶段协议：第一阶段复制全部屏幕像素并生成轻量冻结预览，只有真实预览送达才解除“准备中”状态；第二阶段才写入约 38 MB 全分辨率原图。鼠标移动和框选渲染不再等待原图落盘。
- 触发后先显示完全透明的输入遮罩，阻止误点改变原页面；遮罩本身不改变桌面画面，也不会进入最终截图。
- Windows 11 保留低延迟覆盖层路径，但每次验证截图像素；发现近乎纯黑时自动隐藏覆盖层并重新捕获。
- 原生捕获辅助进程不可用、超时或返回无效图片时自动回退到 Electron 桌面捕获。
- 应用退出时结束截图辅助进程并清理本次运行的临时目录，不增加任务栏窗口。

## 验收

- 黑图单元回归：纯黑图必须被识别，深色但含有效内容的图片不得误判。
- 真实 E2E：验证桌面源、已知颜色裁剪、实际落盘 PNG 以及后续 4 次连续截图均非黑。
- 本机安装版 Windows 10、3072×1920 + 2560×1440 双显示器连续两轮实测：输入遮罩 54/100 毫秒，首次冻结预览 346/348 毫秒，随后连续截图 180/197 毫秒，全分辨率源 465/459 毫秒就绪。
- 启动阶段 30 帧真实指针监测：最大帧间隔 16–17 毫秒、平均 8–9 毫秒；裁剪阶段最大/平均 9/8 毫秒。创建、松开保留、移动和八方向缩放均通过。
- 禁用原生辅助进程后，Electron 降级路径仍能得到正确画面。
