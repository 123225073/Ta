# 拓 Ta 1.12.0：原片直接取用与独立 MP3 录音

- 新录屏停止后，自动保存一份带所选音轨的 MP4，位于项目目录的“原片”文件夹。视频画面不重新编码，音轨只合成一次。
- 录制结束回到素材库；需要剪辑或 SOP 时点击视频卡片进入。点击“打开目录”直接选中文件；“另存视频”只复制已保存的 MP4，不再占用剪辑导出的任务锁。
- 旧录像首次打开目录或另存时准备原片，显示进度，后续复用。导入视频同样准备带声音的 MP4。长录像首次合成仍需要时间，取决于长度和磁盘速度。
- 素材库可以重命名。录制时间作为独立信息保留；本地原片和后续另存的默认名称同步更新。原有项目 ID、剪辑与 SOP 关联不变；Windows 不允许的文件名字符转为横线。已另存到外部的副本不会被修改。
- 新增“独立录音”：默认仅麦克风，可选择麦克风设备或电脑声音。支持暂停/继续、音量指示，停止后自动保存 192 kbps MP3；可试听、重命名、打开目录及另存。
- 独立录音不启动屏幕采集或视频编码；录音设备失效时停止、保留已录片段并提醒。原始音轨保留，以便恢复。

验证：159 项单元测试、原生音频测试、实际 WGC/WASAPI 录制和 Electron 界面测试。覆盖 MP4 音画、MP3 编码及试听、暂停时长、麦克风、重命名和日期保留、目录定位、旧项目准备、多个另存与剪辑导出并存。测试均使用隔离项目，不改动用户素材。
