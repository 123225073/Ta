# 拓 Ta Windows 1.4.0：录屏与可编辑标记

## 使用方式

1. 在顶部导航点击「录屏与剪辑」，或从托盘菜单打开。默认快捷键是 Ctrl+Shift+7。
2. 选择整个屏幕、指定录制框或单个窗口。录制框可在预览图中拖出，再用像素数值精确调整。
3. 按需开启麦克风与电脑声音；两者分别保存。点击「开始录制」，默认倒计时 3 秒。
4. 浮条提供暂停、继续、标记、撤销、清屏和停止。Ctrl+Shift+8 暂停/继续，Ctrl+Shift+9 停止，Ctrl+Shift+0 切换标记/操作桌面。快捷键可在录屏设置中修改。
5. 停止后自动进入剪辑。可分割、删除中间片段、只保留某段、静音、裁切和指定时段放大。
6. 在画面上添加矩形、箭头、画笔、高亮、文字、编号或实色遮挡。选择后可拖动位置，在右侧调整尺寸、颜色和出现/结束时间。
7. 勾选要融合进成片的标记，导出 MP4。取消勾选只影响成片和预览，项目仍保留对象。「隐藏普通标记」会保留已启用的遮挡。

## 标记与放大

标记记录在原视频坐标中，裁切与放大同时作用于视频和标记。先放大画面再添加标记，会反算回原视频位置。选中一个标记后点击「该段放大 2 倍」，会以这个标记为中心；右侧可改为 1.5、2、3 或 4 倍。

这一版的放大是按时间段切换视野，不含自动物体跟踪或 AI 识别。录制时的画笔/高亮会保存笔迹时间，导出时逐步显示；录后补画的标记按设置的时间段显示。

## 保存内容

默认保存在 Windows 视频目录下的「拓 Ta」，按日期和项目编号分文件夹。可在录屏设置中更换目录，已有项目仍可找到。

- `screen.mp4`：原录像，无工具栏和标记。
- `system.wav` / `mic.wav`：选择开启时生成的独立音轨。
- `project.json` 及备份：标题、剪辑、标记、放大、裁切和音量。
- 导出的 MP4：保存到你选择的位置；不覆盖原录像。

录制与编辑记录自动保存。异常结束后优先保留可恢复片段；视频库会标出异常恢复项目。遮挡只处理导出的成片，原录像仍含原始内容。

## 本轮验证与边界

已实测全屏、区域与单窗口；本机显示器为 3072×1920、175% 缩放。录制标记排除、暂停/继续、独立系统/输入音轨保存、剪辑帧数、标记选择、画笔逐步回放、放大对齐、双主题和原文件不变均有短样片验证。

输入音轨测试使用本机「立体声混音」设备，未采集真实人声。尚未完成 30 分钟音画同步与 60 分钟资源稳定性验收，也未覆盖外接屏混合 DPI、设备拔插和磁盘写满。不要据短样片推定这些长时/设备场景已通过。

## 开源复用

复用了 OpenScreen v1.11.0 的 Windows Graphics Capture、Media Foundation、WASAPI、音频混合基础、暂停时间线与分段 MP4，并参考其保留片段算法。按本项目要求适配成独立音轨和标记工程；没有引入其云分享或完整桌面程序。

上游：https://github.com/getopenscreen/openscreen/tree/v1.11.0 。源码归属与修改明细见 `windows/native/openscreen-wgc/TA-UPSTREAM.md`，第三方组件见 `windows/VIDEO-THIRD-PARTY-NOTICES.md`。
