# 拓 Ta 1.12.1

录屏结束后自动保存带声音的 MP4；已有录像、异常退出后恢复的录像，如果还没有可直接使用的原片，启动软件后也会自动排队生成，无需点击“打开目录”或“另存视频”。独立录音同样自动保存 MP3。

- 素材卡片显示排队、自动保存进度及完成后的文件位置。
- 旧录像逐个处理；录制期间暂缓启动下一项后台任务，已开始的保存继续完成。
- 自动保存失败会显示原因并允许重试，原始录制保留；单项失败不会阻塞其他录像。下次启动会重新检查未完成项目。
- 已生成的原片不重复处理，“另存”直接复制。文件名称沿用修改后的素材名称，录制日期保持独立。

MP4 的视频画面沿用录制时已经编码的视频流，只合并音轨并整理为可直接播放的文件。较长录制仍需处理时间，但不用用户手动触发。

验证：161 项单元测试、类型检查、无损预览检查通过；开发版与打包版均实测旧录像在打开界面之前自动生成 MP4，新录屏停止后自动生成带声音的 MP4，MP3 录制与试听、重命名、日期保留及原片直接复制通过。自动队列另覆盖录制期间延后、失败后继续其他项目、重新启动补处理及不重复编码。
