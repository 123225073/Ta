# Ta Windows v1.1.7

发布日期：2026-08-28

## 截图交互

- 顶部“拓 Ta”品牌标题改为原生拖动区域；工作台、设置和窗口控制按钮继续保持可点击。
- 通用截图、取字、翻译、钉图和长截图完成后默认复制图片到 Windows 剪贴板；剪贴板失败不会丢失截图或历史记录。
- 选区内快速双击改为基于两次短按的位置和间隔判断，不再依赖透明窗口中不稳定的浏览器 `dblclick`；完成按钮与 `Enter` 仍保留。
- 设置页新增“开始截图时如何处理拓 Ta 窗口”：自动隐藏、保留当前窗口、每次询问。策略只影响 Ta，不会隐藏其他应用。

## 结果侧栏

- OCR、AI 识图和翻译的内容区独立滚动，长结果可滚动到底。
- “重新识别”和“复制文字”固定在侧栏底部，不会随长内容移出窗口。
- 结果缓存、显式重新识别和模型路由提示继续保留。

## 覆盖层复用与暗屏修复

- Windows GDI 采集期间把复用覆盖窗口置为原生 0 透明度，避免透明 Chromium 窗口的旧合成帧再次进入屏幕位图。
- 冻结预览更新后等待两帧完成绘制再显示覆盖层，杜绝上一轮选区、暗色蒙层和工具条闪回。
- 连续 5 次截图同时验证非黑图、非透明图和绿色见证窗口；原生辅助进程禁用后的 Electron 降级链路也执行同一组回归。

## 验收摘要

- 7 个测试文件、27 个测试通过；TypeScript、生产构建、Electron 启动和 npm 官方安全审计通过。
- 源码版连续两轮原生 GDI E2E 与一轮 Electron 降级 E2E 通过。
- 安装版两轮 E2E 通过：长结果滚动/固定复制、标题拖动、自动复制、双击确认、三态窗口策略、其他窗口保持、覆盖层复用和黑图检测全部通过。
- 风沙 CPA 使用已加密凭据完成合成图片视觉回环；未输出或保存明文 Key。
