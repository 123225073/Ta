# 拓 Ta 1.10.1：录屏删除与窗口尺寸适配

- 视频库新增「删除录屏」。确认后将项目目录整体移入系统回收站，包括原始录屏、独立音轨、剪辑记录、SOP、配图及历史版本。外部导入原文件、项目目录以外的导出文件不在删除范围内。正在录制、导出或 AI 处理时禁止删除。
- 单窗口录制支持移动、调整大小、最大化和恢复。视频画幅固定为开始录制时的尺寸；窗口内容等比例适配，比例不同时留黑边，避免裁掉内容。
- 最小化、关闭、锁屏等导致暂停时，显示前台警告弹窗、提示音和暂停原因。可选择恢复窗口后继续，或停止保存。暂停期间不录制新的画面和声音。
- 切换录屏页面时清除上一页面的操作提示，避免旧剪辑报错残留在录制页。

验证使用隔离目录和专用测试窗口，没有删除用户已有录像。原生窗口测试覆盖扩大、缩小改变比例、最大化、恢复、最小化后继续、关闭提醒、音画时长和四角内容像素；并测试整项目移入系统回收站、取消删除与保护外部文件。
