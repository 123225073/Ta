# 风沙 · 拓 1.14.0：工作台与流畅度优化

这次集中改善已有流程，没有扩展新的剪辑功能。

- 首页使用“风沙 · 拓”品牌，增加直接进入录屏的入口。安装名称、快捷方式与用户资料目录保持兼容。
- 录屏、录音、素材库、剪辑与 SOP 统一夜幕/瓷白主题；紧凑导航、操作分组、预览与时间线分区。小窗口工具栏横向滚动，给画面保留更多空间。
- 素材库支持名称搜索、视频/录音分类，首次呈现 24 项，继续加载更多。文件路径与音轨说明折叠到“文件信息”；录音封面可以播放/暂停。
- 已保存素材停止每秒反复查询状态；自动保存期间仍更新进度，重新聚焦窗口时刷新状态。
- 播放时复用同一素材的媒体元素；缓存轨道布局、音频波形和时长计算，界面播放时钟按录制帧率更新。剪辑工作区按需加载，主界面不预先加载全部剪辑代码。
- 截图和剪贴板辅助代码在构建阶段预编译，避免每次启动临时编译失败；长截图滚轮和钉图检查同样复用辅助程序集。

在本机同一套 20 条素材、240 个轨道片段、11 秒播放用例中，界面线程累计工作时间从 9.41 秒降至 1.96 秒（约减少 79%）；素材列表静置约 3 秒的重复状态读取从 80 次降为 0；跨片段播放不再移除并重建 9 个媒体元素。此为指定测试负载的结果，不代表所有项目的整体速度均提升 79%。

录制自动保存 MP4/MP3、独立音轨、重命名、日期、SOP 与 AI/飞书配置继续保留。录制电脑声音时需检查声音电平：在本次测试的系统输出设备上，Windows 静音会导致回录静音，极低音量也会降低录入电平。

验证范围与交付记录见 [体验和性能验收](./experience-v1.14.0.md)。
