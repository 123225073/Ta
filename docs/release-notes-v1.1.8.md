# Ta Windows v1.1.8

发布日期：2026-08-28

## 动态全局快捷键

- 设置页不再要求手写 `CommandOrControl+Shift+2`。点击快捷键框后直接按下组合键，例如 `Alt + F1`，界面会自动识别并格式化显示。
- Windows 默认值调整为 `Ctrl + Shift + 1…6`：极速取字、通用截图、复制图片、截图钉图、滚动长截图、截图翻译依次对应 1 到 6。
- `Esc` 取消本次录制，`Backspace` 或 `Delete` 清空并禁用该功能快捷键；提供“恢复 Windows 默认值”。
- 普通字母和数字必须搭配 Ctrl、Alt、Shift 或 Win；F1–F24 可以单独使用，避免日常输入被全局劫持。
- 录制期间临时注销旧快捷键，防止用户按组合键时意外启动截图；结束录制后恢复。
- 软件内重复组合会阻止保存；Windows 保留键或已被其他软件占用的组合会显示独立提示。
- 保存后工作台按钮同步显示真实快捷键，不再继续展示写死的默认值。

## 双屏黑图与卡死修复

- Windows 原生 GDI 已成功返回时，不再因另一块副屏接近纯黑而把全部画面切换到 Electron/DXGI。
- 黑色桌面、关闭的副屏或深色内容现在视为合法画面；单屏状态不会误伤其他显示器。
- 解决本机 DXGI 在特定显卡/桌面会话中抓帧失败后持续等待、表现为点击截图卡住的问题。

## 安全与验收

- Vitest 从 3.2.4 升级到 3.2.7，修复构建期文件读取/执行安全公告；npm 官方审计为 0 个漏洞。
- 8 个测试文件、31 个测试通过；TypeScript、生产构建、Electron 启动、源码 E2E 和安装版两轮 E2E 通过。
- 安装版验证 `Alt + F1` 从键盘录入、持久化、全局注册并回显到工作台；同时覆盖选区创建/移动/缩放、双击确认、自动复制、结果缓存、钉图和窗口策略。
