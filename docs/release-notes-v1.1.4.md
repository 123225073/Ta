# Ta Windows v1.1.4

发布日期：2026-08-28

## 修复

- 钉图改为经过主进程校验的显式拖动链路，重新支持移动和工具栏操作；进入鼠标穿透后，把鼠标移回右上角工具栏即可自动恢复交互。
- 钉图现在归属于主窗口并保持 `skipTaskbar`，不会再为每张钉图增加一个任务栏图标。
- 清空“最近拓片”后再截图，后台保存与前台结果页通过显式导航事件同步，不再停留在空历史界面。
- 截图覆盖窗口由每次销毁重建改为按显示器持久复用，连续截图不再增加窗口或渲染进程。
- 覆盖窗口复用时使用捕获代次重置选区，旧选区不会污染下一次截图。

## 实测

- 清空历史后重新截图：文件、索引和结果页三项同时恢复。
- 钉图：主窗口隐藏时仍可见；拖动后原生窗口坐标改变；旋转、穿透恢复、关闭和任务栏排除全部通过。
- 连续截图：3 个循环后的覆盖窗口增长为 0。
- 最终三轮完整 E2E（含安装版）截图框可交互时延：首次/连续分别为 35/41、40/29、26/38 ms。
