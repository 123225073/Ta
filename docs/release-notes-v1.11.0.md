# 拓 Ta 1.11.0：录制中切换范围与异常提醒

- 视频库与 SOP「来源视频」均提供「打开目录」「另存视频」。另存到用户选择的位置，将录制/导入视频的独立声音合入 MP4，保留原始画面，不套用剪辑效果；取消不生成文件，不覆盖已有文件。
- 浮动录制条新增「切换范围」，可切换全屏、指定区域或其他窗口。画面与声音保存在同一个项目、同一个视频中；画幅保持初始尺寸，后续来源等比例适配。暂停时切换成功会继续录制。无效窗口会拒绝切换并提示重新选择。
- 持续黑画面约 5 秒、画面采集超过 8 秒未更新、录制状态超过 10 秒未响应、已开启音轨约 30 秒无声，会提示用户核对。黑色内容和安静会议也可能触发提醒，不能仅凭这两种信号认定故障。
- 窗口最小化或关闭时不再连带暂停声音，会弹窗提示恢复或切换范围。锁屏、休眠仍暂停。异常提示提供切换范围、继续观察、停止保存的操作；磁盘不足和录制程序异常退出会明确提醒已停止录制。
- 原窗口持续黑屏或无新帧时尝试重新捕获同一窗口，不自动扩大到桌面或另一个窗口。切换到全屏由用户选择。
- 系统默认声音设备变化或音频捕获失败时尝试重连，转换为原音轨格式继续保存。浮动条显示当前来源及电脑声音、麦克风音量信号。若飞书单独选择了另一输出设备，需要核对其扬声器/耳机设置；默认设备重连不等于能捕获所有设备的声音。
- 项目内 `recording-events.jsonl` 保存少量采集状态、异常、来源切换及重连事件，便于排查；不记录画面或语音内容。

这次报告的旧录屏已只读核验：约第 20 分钟的原始视频为黑画面，同期系统音轨为零电平，问题存在于原始素材而非 SOP 播放器。不能从这些素材确定飞书当时是否更换了窗口、停止渲染或切换了输出设备，也无法恢复当时未采集到的内容。

验证使用隔离项目、专用测试窗口与测试音频，覆盖黑屏报警且音频持续、窗口缩放、窗口关闭、跨窗口/全屏/区域切换、暂停后切换、无效窗口拒绝、音频采集重连、取消另存与含声音的 MP4。窗口列表中的测试窗口和弹窗选择由自动化控制，采集、编码、切换、音轨和输出文件使用真实原生组件。音频重连由测试信号触发，未修改用户系统默认设备。

未在真实飞书共享会议中完成端到端复现，未覆盖所有显卡、音频设备及长时间会议。Windows 不提供画面的窗口无法保证被窗口捕获接口录下；新版的重点是持续监测、明确提醒和允许及时更换来源。

2026-09-15 验证记录：156 项自动测试、18 项原生音频测试、类型检查、预览一致性和全屏/区域录制回归通过。安装包内实测结果位于 `windows/output/recording-resilience-1789467311757/result.json`：窗口/全屏/区域均在同一个项目内切换，视频 28.200 秒，音频 28.230 秒；黑屏期间音轨仍有有效信号。录制和导入素材另存均包含视频与声音，取消另存不生成文件。窗口缩放与删除回归位于 `windows/output/window-resize-1789467054502/result.json`。升级没有尝试删除或修改用户已有录像。

最终版本还修正了窗口列表中缩略图挤压名称的问题，12 个窗口的滚动和名称可见性检查通过。桌面已安装 1.11.0.0，快捷方式已更新；安装文件与最终构建一致，577 个已有数据及配置文件的安装前后哈希保持不变，记录位于 `windows/output/install-1.11.0/install-result.json`。
