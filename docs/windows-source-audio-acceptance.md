# 1.12.0 原片与录音验收

日期：2026-10-10。验证使用隔离配置与测试项目，不删除、改名或转码用户录像。

| 请求 | 实现 | 验证 |
|---|---|---|
| 录完直接取得 MP4 | 停止时准备带所选音轨的原片；画面流复制，不重新编码；目录按钮定位原片 | 实际 WGC 窗口录制，ffprobe 确认视频和音频轨 |
| 另存慢、任务冲突 | 每个项目只准备一次原片；另存直接复制，与剪辑导出分开 | 两个视频副本与一个 MP3 副本并发；原片修改时间保持不变；模拟剪辑导出占用时仍成功 |
| 重命名与独立日期 | 标题及本地原片文件名同步；保存对话框默认采用新名称；createdAt 保留 | 界面重命名 MP3、视频重命名、保存后文件名与日期核对；同名外部文件不覆盖 |
| 独立 MP3 录音 | WASAPI 麦克风/电脑声音，不创建 WGC 会话或视频编码器 | 真实电脑声音与默认麦克风；MP3 编码、有声音、播放器进度推进；项目无 screen.mp4 |
| 暂停/继续 | 复用 AudioMixer 暂停时钟 | 录制约 4.7 秒，中间暂停约 1.5 秒，成品不含暂停时间 |
| 旧素材兼容 | 首次取用时准备原片，同项目并发去重 | 无 sourceFile 的旧格式项目并发准备，目录仅一个 MP4 |
| 原录屏稳定性 | 保留窗口切换、黑屏提醒与独立音轨 | 真实窗口缩放、黑屏、窗口关闭、全屏/区域切换、音频重连回归通过 |

- 单元测试：32 文件、159 项通过。
- 原生音频测试：18 项通过。
- TypeScript 检查及前端构建通过。
- 开发构建与安装包资源均通过 `source-audio-smoke.cjs`。安装包短素材三次复制约 10 ms；此数字不代表大型文件复制耗时，大文件仍受磁盘读写速度影响。
- 截图原色回归：本机 Windows PowerShell 5 的临时 C# 编译遇到文件保护导致的编译错误；使用 PowerShell 7 内存编译与相应 .NET 引用运行同一捕获实现和像素断言后通过。生产截图实现未修改。
- 新录制停止时仍有音轨合成/MP3 编码阶段，界面提示正在自动保存；旧长录像首次取用也需要准备。完成后后续另存不再编码。

可重复运行：`npm test`、`npm run typecheck`、`npm run build:video`、`node scripts/run-video-check.cjs source-audio-smoke.cjs`、`node scripts/run-video-check.cjs recording-resilience-smoke.cjs`。安装包资源测试设置 `TA_VIDEO_PACKAGED=1`。
