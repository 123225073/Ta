# Ta Windows v1.1.11

发布日期：2026-08-28

## 本次修复

### 自动隐藏不再留下 Ta 虚影

- 自动隐藏模式在 `BrowserWindow.hide()` 前先把 Ta 的原生窗口透明度设为 0；
- Windows 截图辅助进程在 `CopyFromScreen` 前连续等待两个 DWM 合成边界；
- 再次打开工作台或结果页时恢复窗口透明度，不影响后续使用；
- 其他应用不最小化、不隐藏、不改变窗口状态。

### 标注大图先完整适配

- 标注画布根据图片宽高和标注区域的真实可用宽高计算缩放比例；
- 适配完成前隐藏原始尺寸画布，避免点击“标注”时先闪现一帧放大的图片；
- 初始比例不放大小图，也允许超大图片缩小到 5% 以下，确保完整可见；
- 增加缩小、放大、比例显示和“适应窗口”操作；
- 继续按照画布物理像素换算指针坐标，缩放后标注仍落在正确位置。

### 双显示器冻结预览提速

- 多块显示器的全分辨率 PNG 从串行改为并行编码；
- 最终裁图仍来自原始 BGRA 像素，覆盖层仍显示无损物理像素预览；
- 安装版双屏实测冻结首次/连续为 305/279 ms，输入遮罩 50/41 ms 出现。

## 文档调整

- 中文、英文、日文仓库首页改为 Windows 版优先；
- 明确本仓库是上游 Ta 的 Windows 分支改造，并保留 macOS/Swift 源码；
- 只描述当前真实实现，补充隐私、模型路由、构建、已知限制与上游同步建议；
- 安装包、构建目录、OCR 模型副本、Playwright 临时文件和用户数据继续排除在 Git 之外。
