# Ta Windows v1.2.0

v1.2.0 把“拓”从单一截图工具扩展为本地截图入口与图片素材库：用户可以继续使用飞书、微信或 QQ 的成熟截图体验，再把结果安全地汇入拓进行 AI、OCR、重复复制和历史管理。

## 新增

- 设置页增加“外部截图自动收集”，飞书、微信、QQ 独立开关，默认全部关闭。
- 每个应用提供“严格截图识别”和“该应用复制的所有图片”两种模式；严格模式为默认值。微信使用实机专属标记，QQ 使用腾讯签名的专用截图进程，飞书将默认全局截图快捷键与随后出现的飞书置顶截图浮层、同一进程及剪贴板 sequence 绑定；不接受跨应用通用状态标记。
- 新增素材库页面：日期分组、名称搜索、日期筛选、重命名、分页加载、多选、选择当天、全选当前筛选结果和批量导出。
- 新增明确粘贴区域：只有该区域实际获得焦点后按 `Ctrl+V` 才会入库。
- 新增多图片文件导入；PNG、JPEG、WebP、BMP、GIF、TIFF 会统一规范化为 PNG。
- 新增保存路径设置；迁移先逐张复制并校验，完成后切换，旧目录默认保留。
- 历史改为 SQLite 索引和 `年/月/日` 原图目录，默认长期保存且不限制 40 张。
- 旧版 `history/index.json` 自动幂等迁移；失败会在素材库显示并允许重试。

## 安全与可靠性

- 常驻 Win32 监听器只在总开关和至少一个应用开关同时开启时运行。
- 自动收集先判断剪贴板元数据，再读取图片；未知进程、路径异常、身份不一致、签名异常、证书异常、格式不匹配或 sequence 变化都会拒绝。
- 图片读取前后两次重新检查 sequence、PID、路径、签名证书，快速连续变化只保留最新待处理事件。
- 监听器每次重新执行 Authenticode 验证，不复用路径/时间戳弱缓存；异常退出使用指数退避重启并限制输出缓冲。
- 飞书快捷键识别拒绝注入按键，只接受真实可见的飞书置顶截图浮层；意图绑定浮层 PID、完整路径与触发前 sequence，并在浮层关闭后快速失效。
- 卡片只读取受限尺寸缩略图；图片输入限制为 32,000,000 像素和 80 MB，避免压缩炸弹或超大原图拖垮主进程。
- 存储迁移期间写操作由主进程排队，底层同时拒绝绕过队列的直接写入。
- 批量导出使用异步文件复制；删除前 UI 确认，原图进入 Windows 回收站。

## 保留边界

- v1.2.0 不增加自定义文件夹、收藏夹、标签、云同步和录屏。日期归档与批量导出覆盖第一版管理需求。
- 第三方应用私有剪贴板格式和程序结构可能随版本变化；微信专属标记与 QQ 专用截图程序已在本机确认。飞书自定义快捷键或界面按钮无法建立快捷键上下文时坚持失败关闭。识别不到时，用户可明确粘贴、文件导入，或只对该可信应用开启“所有图片”模式。
- 自动入库不自动调用 AI。只有用户在结果页主动使用 AI 识图或翻译时，图片才会发送到所配置的服务。

验证证据见 [Windows 验收报告](./windows-acceptance.md) 和 [v1.2.0 对抗审查](./windows-external-capture-library-adversarial-review-v1.2.0.md)。
