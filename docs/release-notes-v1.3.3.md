# Ta Windows v1.3.3

v1.3.3 让“拓”内部的图片在各个位置都具备一致、直接的右键操作。

## 新增

- 工作台“最近拓片”、素材库卡片、截图结果页、标注画布和钉图窗口均支持右键。
- 统一 Windows 原生菜单：`复制图片`、`下载图片…`。
- 工作台和素材库从本地历史记录读取完整原图，不会复制低分辨率缩略图。
- 标注编辑区会先渲染当前画布，再复制或下载包含全部现有标注的 PNG。
- 下载使用系统另存为窗口，并优先沿用素材名称。

## 安全与回归

- 右键请求只接受经过校验的历史记录 ID、PNG 数据或当前钉图引用，不接受任意本地文件路径。
- 钉图窗口不能读取主窗口的其他素材，主窗口也不能伪装成钉图窗口。
- 编辑画布忽略非左键绘制，右键不会产生多余标注。
- 真实 Electron E2E 覆盖工作台、素材库、结果页、编辑区和钉图五个入口，并校验菜单文字、原图尺寸、窗口权限和编辑后图像哈希。

## 安装

安装包：`windows/release/Ta-Windows-1.3.3-x64-Setup.exe`

覆盖安装不会主动删除用户设置、加密后的 API Key、历史索引或素材库。
