# 拓 Ta · Windows 版

这是 Ta 的 Windows 10/11 x64 客户端，版本为 **1.10.0**。它不是在 Windows 上勉强运行 Swift/macOS 程序，而是保留原产品定位与品牌，重新实现 Windows 的屏幕捕获、快捷键、托盘、安全存储、剪贴板、素材库、安装和更新边界。

## 直接安装

1. 运行 `release/Ta-Windows-1.10.0-x64-Setup.exe`；
2. 按安装向导选择目录；
3. 从桌面快捷方式“拓 Ta”启动；
4. 关闭主窗口后，程序继续驻留系统托盘，全局快捷键仍然有效。

卸载默认保留设置和截图历史，避免误删用户资料。

## Windows 功能

- **AI 剪辑 CLI**：安装目录 `resources/cli/ta-video.cmd` 提供项目查询、原片截帧、批量编辑预演/应用、撤销/重做、导入与导出。用法见 [AI 调用说明](resources/cli/AI-EDITING.md)。

- **录屏与 SOP**：录完进入步骤文档，支持视频导入、画面与讲解生成 SOP、AI 对话修改及补帧、手工补图、配图裁切/高亮/遮挡、Ctrl+Z 撤销/重做、版本恢复、飞书 CLI 图文发布、Word/PDF/HTML/Markdown 导出。详见 [1.10.0 使用说明](../docs/release-notes-v1.10.0.md)。

- **录屏与剪辑**：全屏、窗口、自选区域录制，暂停/继续，麦克风与系统音独立保存；录后剪切片段、裁剪、局部放大，添加或修改标记，并选择哪些标记融入 MP4。标记随画面缩放和裁剪保持对齐。详见 [1.4.0 使用说明](../docs/release-notes-v1.4.0.md)。

- 多显示器区域截图；松开鼠标即保留选区，框内拖动可移动、四边四角可缩放，快速双击/完成按钮/`Enter` 均可完成；`Esc`/右键取消；
- 微信式智能框选：截图开始时一次性读取 Windows/DWM 顶层窗口边界，鼠标悬停自动高亮最上层窗口，单击锁定，拖动仍可自由框选；选区保持冻结画面的原色，只把四周置灰；
- 框选冻结画面使用与物理屏幕同尺寸的无损 PNG，不再把 3072px 桌面压成 896px JPEG 后放大，文字和细线保持清晰；
- 截图完成后默认复制图片到剪贴板；“快速截图”会同时保存到最近拓片并直接退出覆盖层，不打开图片编辑页；结果页仍保留手动复制按钮；
- “设置 → 截图与翻译”可选择自动隐藏 Ta、保留 Ta 或每次询问；自动隐藏会先把 Ta 原生窗口透明化并隐藏，再由截图宿主等待 DWM 完成合成，防止原位置留下淡化虚影；此策略只影响 Ta，不会隐藏其他应用；
- 顶部品牌标题区域可直接按住拖动窗口；导航和最小化/最大化/关闭按钮保持独立可点击；
- OCR、AI 识图和翻译的长结果在侧栏内独立滚动，底部“重新识别/复制文字”操作区始终固定可见；
- 图片进入标注编辑区后按 `Esc` 可直接返回结果页，行为与右上角“取消”按钮一致；
- 标题栏新增“瓷白 / 夜幕”快速切换；“瓷白典藏”使用暖瓷白、墨色、朱砂红和玉石绿，并覆盖工作台、素材库、设置、结果与标注页。选择会立即写入本地设置，下次启动继续使用；
- 截图覆盖层与隐藏的 Windows 原生 GDI 辅助进程在应用启动后预热；双显示器先一次性冻结全部桌面像素并显示全分辨率无损预览，再写入全分辨率原图。本机安装版实测约 0.04–0.07 秒接管输入、首次约 0.53 秒/连续约 0.39 秒完成可框选冻结画面；辅助进程不可用时会明确报错，不把未知黑图或低清图交给用户；
- 每次截图都会在进入预览、裁剪和历史记录前检查亮度、方差与近黑像素占比；Windows 11 的受保护覆盖层若被驱动捕获成黑屏，会自动隐藏覆盖层并重新获取画面；
- 六组可动态录制的全局快捷键：点击输入框后直接按组合键即可自动填入；录制时临时暂停旧快捷键，保存前检查重复与注册冲突；
- 简体中文 + English 的 Tesseract.js 离线 OCR，语言数据随安装包提供；
- OpenAI-compatible、Anthropic Claude、Google Gemini 三类协议；
- Windows `safeStorage` 加密 API Key，界面不会回显已保存密钥；
- 云端识图/翻译前确认，本地截图与 OCR 不上传；
- 自动滚轮长截图、重复帧停止、相邻帧位移匹配和拼接；选区中的固定顶栏/底栏会从各帧正文中分离，并在成品中只保留一次；
- 长截图期间使用独立状态浮层显示已识别帧数、自动下滑、固定栏分析和拼接状态；浮层不抢焦点，并在每帧像素采集前隐藏、采集后恢复，不会进入截图；
- 矩形、椭圆、箭头、画笔、高亮、文字、编号、马赛克、模糊、橡皮、撤销/重做；大图进入标注时按可用宽高完整适配，适配完成前不显示原始尺寸闪帧，并提供缩小、放大和“适应窗口”；
- 置顶钉图、缩放、旋转、翻转、透明度和鼠标穿透；
- 飞书、微信、QQ 外部截图按应用独立开关自动收集：严格模式校验剪贴板所有者、进程路径、Windows 数字签名、证书主题和同一 sequence；微信使用真实专属格式，QQ 使用签名有效的专用截图进程，飞书使用默认全局截图快捷键与真实置顶截图浮层上下文；不确定时不读取图片；
- 只有在素材库粘贴区域获得焦点时，`Ctrl+V` 才会明确导入图片；也可一次选择多张文件导入，不会把用户在其他软件中的普通粘贴动作误收集；
- SQLite 本地素材库默认不限张数，原图按 `年/月/日` 目录保存；支持重命名、搜索、日期筛选、多选、选择当天、全选当前筛选结果和异步批量导出；
- 保存根目录可由用户修改；迁移先复制并校验，完成后再切换索引，原目录默认保留；旧版历史迁移失败会在素材库提示并可重试；
- 手动重新复制、PNG 保存和本地一键美化；
- 工作台最近拓片、素材库、结果页、标注画布和钉图统一支持右键“复制图片/下载图片”；历史卡片读取原图而非缩略图，标注画布输出当前渲染结果；
- 系统托盘、开机启动、启动最小化与 NSIS 安装/卸载。

## 默认快捷键

| 功能 | Windows 快捷键 |
|---|---|
| 极速取字 | `Ctrl+Shift+1` |
| 通用截图 | `Ctrl+Shift+2` |
| 快速截图 | `Ctrl+Shift+3` |
| 截图并钉住 | `Ctrl+Shift+4` |
| 滚动长截图 | `Ctrl+Shift+5` |
| 截图翻译 | `Ctrl+Shift+6` |

快捷键可在“设置 → 全局快捷键”中修改：点击输入框后直接按键，例如 `Alt + F1`，无需手写 Electron 语法；`Esc` 取消，`Backspace` 清空。Windows 默认使用 `Ctrl + Shift + 1…6`，也可一键恢复默认。若组合键重复或被其他软件占用，界面会明确提示，不会静默覆盖。

## AI 服务配置

在“设置 → 模型服务”中选择协议、填写 Base URL、模型名称和 API Key。默认提供 OpenAI、DeepSeek/兼容服务、Anthropic 与 Gemini 配置模板。

模型标签中的“当前”表示已经保存并实际生效的服务；只切换标签时会显示“保存后使用”，必须点击“保存设置”才会改变路由。AI 识图、截图翻译和自动翻译快捷键共同使用当前服务；极速取字使用本地 Tesseract OCR，普通截图、复制、钉图、长截图、标注和本地美化不调用云端模型。

此工作区还预置“风沙 CPA”：`https://cpa.fengsha.online/v1`、`gpt-5.6-terra`。`npm run configure:cpa` 可从本机“风沙 SAP 运维任务台”经匿名管道迁移已加密 CPA 凭据，随后由 Ta 使用自己的 Windows `safeStorage` 重新加密；`npm run verify:cpa` 使用合成测试图验证真实视觉请求，不会发送桌面截图。

注意：DeepSeek 官方 `deepseek-chat` 是文本模型，不能直接读图；如需用 DeepSeek OCR 或其他视觉模型，请把 Base URL 和模型名改成实际支持图片输入的 OpenAI-compatible 服务。Ta 不会替用户下载或启动大型模型。

## 长截图使用

1. 把目标页面滚动到开始位置；
2. 按 `Ctrl+Shift+5`，框选需要连续捕获的内容区；
3. 把鼠标保持在该区域内，Ta 会向下滚动并捕获；右上角状态浮层会显示当前帧数与工作阶段；
4. 内容不再变化或达到设置中的最大帧数后，Ta 会剔除重复固定栏、拼接滚动正文并打开结果页。

持续动画、视频、半透明悬浮层、虚拟列表和滚动时大幅重排的页面仍可能影响匹配质量。

## 从源码构建

要求 Node.js 22 或更高版本，以及 Visual Studio C++ Build Tools（包含 Windows SDK、CMake、Ninja）。当前测试机使用 Node.js 23.11.0。

```powershell
cd windows
npm install --legacy-peer-deps
npm run typecheck
npm test
npm run test:preview-fidelity
npm run build
npm run smoke
npm run smoke:clipboard
npm run smoke:e2e
npm run build:video
npm run prepare:video
npm run dist
```

如果 GitHub 的 Electron 二进制下载受网络影响，可以只为当前终端指定镜像：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
node node_modules/electron/install.js
```

构建结果位于 `release/`。`npm run smoke:e2e` 会读取当前屏幕，并在隔离的临时用户目录中校验源图、裁剪图和落盘 PNG 的亮度、颜色方差、已知颜色区域与哈希；测试结束后删除临时图片，不输出屏幕图像。

## 当前边界

- Windows 版已经覆盖日常截图主链路，但没有移植 macOS 的 Agent Bridge、`ta` CLI 与 DeepSeek Harness 插件；这些仍使用原 macOS 实现。
- Windows 框选支持每个显示器独立选区和窗口级自动吸附，暂不支持一次选区跨越多个显示器；控件级 UI Automation 吸附和像素边缘兜底尚未加入。
- Windows 图片翻译当前输出结构化译文，没有把文字自动重绘回复杂原图。
- Windows 本地美化为确定性的留白、纹理和阴影模板，不宣称为尚未接入的 AI 生成式美化。
- 外部截图严格识别依赖第三方应用当前的专属格式、专用截图进程或默认快捷键行为；应用升级、自定义飞书快捷键或从界面按钮启动导致无法确认时会失败关闭，不会扩大为全局图片监听。用户仍可明确粘贴或导入。
- 安装包未做商业代码签名，Windows SmartScreen 可能在首次启动时要求确认发布者。

这些边界会在界面与文档中如实保留，不把未实现能力标记为已完成。
